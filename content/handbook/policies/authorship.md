# 저자권·논문 정책 (ION Lab)

> ⚠️ **문서 상태**: 초안. 사례별 판단 요소가 많음. 애매한 경우 PI 확인 필수.

## 1. 1저자 결정

- **결정 시점**: **논문 작성 시**
- **결정 기준**:
  - **아이디어** 오너십
  - **주도 기여** (연구 전 과정에서 실질적 리드)
- **공동 1저자**: 필요 시 인정 (기여도가 실질적으로 동등한 경우)

**주의사항**
- 실험 코드 대부분을 짰다는 것만으로 1저자 자동 결정 아님. 아이디어 오너십도 종합적 고려.
- 이견 있을 시 PI가 최종 판단.

## 5. 논문 투고 프로세스

### 타임라인 (마감 역산)

| 시점 | 상태 |
|---|---|
| 마감 **1개월 전** | **초안 필요** (rough draft) |
| 마감 **2주 전** | **대략적인 완성본** 필요 (near-final) |
| 마감 ~ 완성본 | PI 라운드 반복하며 완성 |

### PI 리뷰 라운드
- 투고 전 **최소 3번 이상** PI 리뷰 라운드 필요
- 초안 완성 후 여러 round의 editing 필요
- 각 라운드 사이 학생이 반영·개선

### 공동저자 리뷰
- 공동저자들끼리 **지속적으로 peer-review** 수행
- 마지막 순간에 한꺼번에 리뷰 요청하지 말 것

**투고 임박 시 팁**
- 마감 며칠 전 draft 완성은 위험. PI 스케줄과 안 맞을 수 있음.
- 학기 중 마감 몰릴 때 특히 앞당겨 준비.

## 7. Acknowledgment

### 기본 원칙
- **Funding 위주**로 기재 (관련 grant 번호 포함)
- 매번 **PI에게 확인 필수** (grant 별 표기 방식 상이할 수 있음)

### 포함 대상
- **필수**: 이 연구를 지원한 grant / funding
- **선택** (PI 확인 후): GPU·컴퓨팅 지원, 대화·피드백 제공한 외부 연구자, 코드·데이터셋 원저자 등

### 형식 예시 (실제 문구는 논문·grant에 따라 조정)
```
This work was supported by [Grant Name] (Grant No. [XXX-XXX]).
The authors thank [names] for helpful discussions.
```
