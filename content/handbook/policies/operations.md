# 연구실 운영 규칙 (ION Lab)

> ⚠️ **문서 상태**: 초안. 실제 운영하면서 다듬어 나갈 예정.

## 1. 랩 세미나 (그룹 미팅)

- **주기**: **매주 수요일 15:00** (2026 가을 학기부터. 이전에는 화요일 16:00)
- **시간표에 따라 변경 가능** (학기별 조정)
- **소요 시간**: 약 1시간
- **형식**: **논문 발표** — 최근 논문 1편을 번갈아가면서 발제
- **참석**: **대면 원칙**, 전원 참석
- **비고**: 리딩 그룹 = 랩 세미나와 동일

### 진행 방식 (2026 가을 개편)

지금은 **최소한의 두 가지 규칙만** 둡니다. 형식을 무겁게 만들기보다,
"읽고 와서 이야기가 오가는 자리"를 먼저 만드는 것이 목적입니다.

1. **사전 읽기 — 참석자 전원이 최소 abstract + intro는 읽고 옵니다.**
   전부 읽어 오라는 뜻이 아닙니다. 발표를 처음부터 따라올 수 있을 만큼만.
2. **발표 후 discussion을 장려합니다.**
   질문·반론·"우리 연구에 쓸 수 있나"는 환영입니다. 발제자가 답을 다 알 필요는 없습니다.

> 30분 발표 / 20분 토론 분리, 지정 discussant 같은 심화 개편은
> 이 방식을 한 학기 돌려보고 다시 논의합니다.

**발제자 팁**
- 발제 논문은 사전 공유 (구체 시점 TODO — 며칠 전?)
- 발제 자료 준비 (슬라이드 or 노트)
- 요약: 문제 / 기여 / 방법 / 결과 / 한계 / 우리 연구와의 연결

### 발표 순서 (로테이션)

- **학기 초에 학생끼리 협의해서 배정**합니다. PI가 지정하지 않습니다.
- 개인 사정이 생기면 **서로 교환 가능**합니다 (Slack에서 합의 후 파일 수정).
- 배정표는 공개 파일입니다 — 누구나 확인·수정할 수 있습니다.

```
content/lab-seminars/_rotation-YYYY-학기.yaml    예: _rotation-2026-fall.yaml
```

사이트에서는 [Seminars](/lab-seminars) 페이지에 표로 보입니다.

### 세미나 노트 (아카이브)

발표가 끝나면 **발제자가** 요약과 discussion 내용을 정리해 남깁니다.
나중에 "그 논문 우리가 언제 읽었지?"를 검색할 수 있게 하기 위한 것입니다.

```
content/lab-seminars/[학기]/YYYY-MM-DD.md        예: 2026-fall/2026-09-03.md
```

`content/lab-seminars/_template.md`를 복사해서 쓰세요.

## 2. 1:1 미팅 (PI ↔ 학생)

**1:1은 두 종류입니다.** 섞지 않는 것이 핵심입니다.

| | 연구 1:1 | Personal 1-on-1 |
| --- | --- | --- |
| 주기 | 매주 | 월 1회 |
| 시간 | 약 60분 | 약 30분 |
| 다루는 것 | 연구 진행, 막힌 것, 다음 스텝 | 진로·웰빙·피드백·개인 상황 |
| 주도 | 학생이 아젠다 준비 | 학생이 꺼내는 대로 |
| 참여 | 필수 | **선택** |

연구 얘기는 연구 1:1에서 충분히 합니다. Personal 1-on-1까지 연구 진도 얘기가
되어버리면 그 자리를 따로 둔 의미가 없습니다.

### 2.1 연구 1:1

- **주기**: **매주 한 번** (2026 가을 학기부터. 이전에는 "매주 혹은 격주")
- **소요 시간**: 약 1시간
- **시간대**: 학생마다 PI와 협의해서 정합니다
- **사전 준비 필수**: **아젠다 미리 공유**

**아젠다 공유 원칙**

- 학생이 아젠다를 미팅 **전에** PI에게 공유합니다
- 논의할 항목, 질문, 결정이 필요한 사항
- 미팅 후에는 결정·다음 스텝을 문서화합니다

아젠다가 없으면 미팅이 "요즘 어때요"로 시작해서 30분이 지나갑니다.
막힌 것 세 줄이라도 미리 보내주세요.

노트는 private 저장소에 남습니다 (본인 + PI만 봅니다):

```
lab-os-private/content/one-on-ones/<member-id>/YYYY-MM-DD-one_on_one.md
```

### 2.2 Personal 1-on-1

- **주기**: **월 1회**, 약 30분
- **연구 얘기는 하지 않습니다.** 진로, 커리어 고민, 컨디션, 랩 생활,
  PI에 대한 피드백, 개인 상황 — 무엇이든 됩니다.
- **학생이 주도하고 PI는 주로 듣습니다.** 준비 안 해와도 됩니다.
- **참여는 선택입니다.** 건너뛰어도 되고, 하고 싶을 때 요청해도 됩니다.
- 기록은 가볍게 몇 줄만 남깁니다 (follow-up이 필요한 경우에만).

> PI에 대한 불만이나 랩 운영에 대한 의견을 말해도 되는 자리입니다.
> 그러라고 만든 자리입니다.

노트 위치 (⚠️ 폴더 신설 예정 — TODO):

```
lab-os-private/content/personal-1on1s/<member-id>/YYYY-MM-DD-personal_1on1.md
```

### 시스템 통합 (설계 노트)

- **1:1 아젠다·이력은 lab-os에서 지속적으로 track할 수 있게 구축 예정**
- 학생별 1:1 히스토리 (본인 + PI만 볼 수 있게)
- 다음 미팅 전까지 완료할 액션 아이템 트래킹
- (구현 시점: Phase 2 이후)
- Personal 1-on-1은 트래킹 대상이 아닙니다 — 횟수를 세거나 통계를 내지 않습니다

## 3. 리딩 그룹

- **랩 세미나와 동일**하게 진행 (별도 리딩 그룹 없음)
- 각자 최근 논문 발제 → 토론

## 4. 코어타임·재실

### 코어타임
- **오전 10시 ~ 오후 5시 재실 원칙**
- 이 시간에는 랩에 있는 것이 기본

### 원격 근무
- 필요한 경우 가능
- **미리 논의 필수** (사전 승인)

### 출결 트래킹
- 자기 보고 형태
- 구축 중인 **internal 시스템 (`/internal/attendance`)** 에서 체크인·체크아웃
- 통계·랭킹 없음, "지금 연구실에 누가 있는지" 공유 목적

---

## 5. 방학·휴가

### 방학 중 랩 활동
- **방학 중에도 랩 활동은 그대로 유지**
- 오히려 더 많은 성과가 기대됨 (시간 확보 가능)
- **코어타임 원칙도 방학 중 적용**

### 자유 방학
- 여름·겨울 각각 **1주일씩 자유 일정 가능**
- **랩 캘린더에 사전 마크 필수**
- 분할 사용 가능하나 **한 번에 사용 권장**

### 병가·경조사·긴급 상황
- 유연하게 활용 가능
- **PI와 사전 논의 필수** (아주 위급한 경우는 제외)

## 6. 학회 참석·출장

### 참석 자격
- **논문 accept 후 발표 예정**인 경우 → 학회 참석 지원

### 비용 지원
- 학교 지원 금액 + **랩에서 차액 지원**
  - 지원 범위: 숙박, 출장비, 학회 등록비 등
- 학교 지원 부분은 소속 학과·대학원 규정 확인
