# 캘린더 구독하기

## 이 문서를 읽으면

랩 일정과 학회 마감을 **본인 캘린더 앱에서** 보게 됩니다. 사이트를 열어보지 않아도
그룹 미팅 시간이 폰에 뜨고, 투고 마감이 다가오면 알림이 옵니다.

## 어디에 무엇이 있나

| 보고 싶은 것          | 어디서                                               |
| --------------------- | ---------------------------------------------------- |
| 랩 일정 (미팅·세미나) | **Google Calendar 구독** → 아래 1번. 이게 기본입니다 |
| 랩 일정 (사이트에서)  | `/internal/calendar` — 랩 구성원만                   |
| 학회 투고 마감        | [/calendar](/calendar) (공개)                        |
| 과제 리포트 마감      | `/internal/deadlines` — 공개 페이지에는 없습니다     |
| 이번 주 학회 마감     | Slack (매주 월요일 아침)                             |

> **랩 일정은 공개 사이트에 나오지 않습니다.** 미팅 제목에 사람 이름이나 면담
> 성격이 드러나기 때문입니다. 그래서 일정을 보는 정식 경로는 **GCal 구독**이고,
> 사이트의 `/internal/calendar` 는 보조 수단입니다.
>
> 지금은 `/internal/*` 에 로그인이 없어 주소를 아는 사람은 들어갈 수 있습니다.
> 그래서 배포본에는 일정이 아예 실리지 않게 해 뒀습니다 — 즉 지금
> `/internal/calendar` 를 열면 비어 있는 게 정상입니다.
> Phase 2 에서 인증이 붙으면 그때 채워집니다.
> | 이번 주 요약 | Slack (매주 월요일 아침) |

## 1. 랩 캘린더 구독하기

랩 공식 캘린더(`lab-general`)를 본인 캘린더 앱에 붙입니다. **일정을 보는 정식
경로가 이것입니다.**

> **TODO(PI):** GCal → 캘린더 설정 → 캘린더 통합에서 구독 주소를 복사해
> 아래 `<주소>` 자리에 넣으세요. 랩 구성원에게만 공유하면 됩니다.

### 웹 (Google Calendar)

1. [calendar.google.com](https://calendar.google.com) 접속
2. 왼쪽 **다른 캘린더** 옆 **+** → **URL로 추가**
3. 랩에서 받은 iCal 주소를 붙여넣고 **캘린더 추가**

### iPhone

**설정 → 캘린더 → 계정 → 계정 추가 → 기타 → 구독 캘린더 추가** 에 같은 주소를
넣습니다. Google Calendar 앱이 아니라 iOS 설정에서 해야 합니다.

### Android

Google 계정으로 위 **웹** 절차를 한 번 하면 Android 캘린더 앱에 자동으로 나타납니다.
앱에서 안 보이면 캘린더 앱 → 설정에서 해당 캘린더의 **동기화**를 켜세요.

### 알아둘 것

- **읽기 전용입니다.** 구독한 캘린더에는 일정을 추가·수정할 수 없습니다.
  일정 변경은 캘린더 소유자(PI 또는 랩 매니저)에게 요청하세요.
- 구독 캘린더는 **즉시 갱신되지 않습니다.** Google은 보통 몇 시간에 한 번 가져갑니다.
  방금 바뀐 일정이 안 보여도 정상입니다. 급한 변경은 Slack으로 옵니다.

## 2. 학회 마감 보기

[/calendar](/calendar) 에 D-30 이내 마감이 배지와 함께 뜹니다. 이 페이지는 공개입니다
— 학회 마감은 공식 CFP에 이미 공개된 정보이기 때문입니다.
목록에 어떤 학회가 오르는지는 `content/conferences.yaml` 의 `tracked_venues` 가 정합니다.

**낼 생각이 있는 학회가 목록에 없다면** PR로 추가하세요:

```yaml
tracked_venues:
  - name: COLM
    source: colm # huggingface/ai-deadlines 의 파일명
    category: nlp
```

날짜는 주 1회 자동으로 채워집니다. 직접 적을 필요가 없습니다.

> ⚠️ **사이트의 날짜는 참고용입니다.** 자동 수집한 값이라 upstream이 틀릴 수 있습니다.
> **투고를 결정했다면 공식 CFP에서 직접 확인**하고, 다른 날짜를 발견했으면
> `content/conferences.yaml` 의 `conferences` 에 적어 덮어쓰세요
> (`verified_by` 에 본인 member id, `verified_on` 에 확인한 날짜).

## 3. 주간 Slack 요약

매주 월요일 아침, **임박한 학회 마감**이 Slack에 올라옵니다.
랩 일정은 담기지 않습니다 — 채널에 누가 있는지 자동화가 알 수 없어서,
일정은 각자 구독한 캘린더에서 봅니다.

## 잘 안 될 때

| 증상                             | 원인                               | 해결                                                |
| -------------------------------- | ---------------------------------- | --------------------------------------------------- |
| 구독했는데 일정이 하나도 안 보임 | 캘린더가 아직 비어 있음            | 캘린더 소유자에게 일정이 등록됐는지 확인            |
| 방금 추가된 일정이 안 보임       | 구독 캘린더 동기화 주기 (몇 시간)  | 기다리거나 GCal 웹에서 직접 확인                    |
| 시간이 한 시간씩 밀려 보임       | 캘린더 앱의 시간대 설정            | 앱 시간대를 `Asia/Seoul` 로                         |
| 마감이 D-30 이내인데 목록에 없음 | 그 학회가 `tracked_venues` 에 없음 | 위 2번대로 PR로 추가                                |
| 마감 날짜가 공식 CFP와 다름      | upstream 데이터가 틀림             | `conferences` 에 적어 덮어쓰기 (위 2번의 경고 참고) |
